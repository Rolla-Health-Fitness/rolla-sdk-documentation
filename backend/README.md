# Rolla Partner API — Backend Integration Guide

A complete guide to integrating with Rolla's Partner API from your backend. This guide covers authentication, user management, data retrieval, and best practices for server-to-server communication.

## Table of Contents

1. **[Overview](01-overview.md)** — Partner API overview, base URL, credentials, and onboarding
2. **[Authentication](02-authentication.md)** — OAuth 2.0 Client Credentials flow, token management, validation, and revocation
3. **[User Management](03-user-management.md)** — Register users, authenticate existing Rolla users, check status, and disconnect
4. **[Data Endpoints](04-data-endpoints.md)** — Activities, goals, health data, weight, blood pressure, insights, and device info
5. **[Error Handling](05-error-handling.md)** — Error response format, HTTP status codes, retry strategies, and integration checklist

---

## Quick Start

1. Start with [Overview](01-overview.md) to understand the API and obtain credentials
2. Follow [Authentication](02-authentication.md) to implement token management
3. Use [User Management](03-user-management.md) to register and manage users
4. Access health data via [Data Endpoints](04-data-endpoints.md)
5. Review [Error Handling](05-error-handling.md) for production readiness
